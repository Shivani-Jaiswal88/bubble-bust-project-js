# 🫧 Bubble Burst Game

A simple and interactive **Bubble Burst Game** built using **HTML, CSS, and JavaScript**.

The goal of this project is simple: **click on the bubbles to burst them!** 💥

This project was created as a practice project to improve my understanding of **HTML, CSS, JavaScript, DOM manipulation, and events**.

## 🎮 How to Play

1. Open the game.
2. Click on a bubble.
3. The bubble bursts when clicked.
4. Enjoy the game! 🫧💥

## ✨ Features

* 🫧 Interactive bubbles
* 🖱️ Click-to-burst functionality
* 🎨 CSS-based bubble styling
* ⚡ JavaScript event handling
* 🌐 Simple browser-based game

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

This project was created for **HTML, CSS, and JavaScript practice**, especially to understand:

* DOM manipulation
* Event handling
* Click events
* Dynamic interaction
* CSS styling
