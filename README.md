## Bubble Burst Game
 A simple Bubble Burst Game built with HTML, CSS, and JavaScript for practicing DOM manipulation and JavaScript events.
[live link]( https://shivani-jaiswal88.github.io/bubble-bust-project-js/)

# How to Play
1. Open the game
2. Click on a bubble
3. The bubble bursts when clicked.
4. Enjoy the game

# Features
1. Interactive bubbles
2. Click-to-burst functionality
3. CSS-based bubble styling
4. JavaScript event handling
5. Simple browser-based game

# Technologies Used
1. HTML5
2. CSS3
3. JavaScript
